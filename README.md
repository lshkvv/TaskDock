# TaskDock

Консольный запуск программ под Windows: подать вход, забрать stdout и stderr, сравнить эталон с решением.

Сейчас в репозитории есть пример, на котором это уже можно проверить без самого TaskDock.

```sh
./examples/pair-sum/check.sh
```

`cases/ok.in` — оба ответа 2. `cases/fail.in` — эталон печатает 3, решение печатает 2.
Генератор с `--seed 42 --case 7 --size 6` даёт то же расхождение. Остальные случаи 1–6 и 8 при seed 42 совпадают.
